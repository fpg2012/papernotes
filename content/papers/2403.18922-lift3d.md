## 1. TLDR

{{< figure src="/figures/lift3d-teaser.gif" alt="Lift3D 概览" width="80%" >}}
{{< center >}}*从 2D 模型的不一致多视图预测（中）到 Lift3D 的 3D 一致输出（右）。来源：论文 Fig. 1*{{< /center >}}

- **领域**: 3D 视觉 / Feature Lifting
- **任务**: 把任意 2D 视觉模型提升到 3D — 输入多视图图像，输出是 3D 一致的（不同视角下结果连续不跳变）
- **问题** (§1): 
  - 每个 2D 视觉模型（分割、风格迁移、上色、超分……）要扩展到 3D 都需要单独设计 + 场景级优化
  - 3D 数据远少于 2D 数据
- **核心贡献**: 将通用化新视角合成（GNVS）的渲染管线拓展到**特征空间**，用 DINO/CLIP 的特征图代替 RGB 训练渲染器。学成后任意 2D 模型的中间特征都可以送入这条渲染管线，零样本实现 3D 一致输出。
- **结果**: 训练时只见过 DINO/CLIP 的特征空间，但泛化到风格迁移、超分、开词汇分割、上色等**其他任务的特征空间**，甚至超过专门为此任务设计的 3D SOTA。

## 3. 核心思路：不是单图预测，而是多视图渲染+特征插值

{{< figure src="/figures/lift3d-pipeline.png" alt="Lift3D 整体流程图" width="100%" >}}
{{< center >}}*Lift3D 总体架构：① 2D encoder 提取源视图特征 → ② GNVS 渲染器在新视角上插值特征 → ③ 2D decoder 合成最终输出。来源：论文 Fig. 2*{{< /center >}}

### 先搞清一点：Lift3D 并不从单图预测 3D feature volume

这不是一个「单张图 → 3D 体素」的预测器。Lift3D 的输入是 **多个已标定视角的图像 + 目标新视角的位姿**，输出是目标视角上**3D 一致的特征图**。

### 3.1 基础：通用化新视角合成（GNVS）— §3

Lift3D 建立在 IBRNet 的 GNVS 管线之上 (§3, Eq. 1)。先回顾其基本流程：

给定 N 个已标定源视图 $\{\boldsymbol{I}_i, \boldsymbol{P}_i\}_{i=1}^N$（图像 + 相机位姿），要合成目标新视角 $\boldsymbol{I}_T$：

1. **特征提取**：对每个源视图，用 CNN 提取深度卷积特征 $\boldsymbol{F}_i = \mathcal{F}_{\text{conv}}(\boldsymbol{I}_i)$
2. **Ray casting**：对目标视图的每个像素，沿光线采样 K 个 3D 点 $\{\boldsymbol{x}_j\}_{j=1}^K$
3. **极线投影 + 特征查询**：将每个 3D 点 $\boldsymbol{x}$ 投影到每个源视图上，查找对应位置的特征
   $$\boldsymbol{f}(\boldsymbol{x}) = \mathcal{F}_{\text{view}}\big(\{\boldsymbol{F}_i(\Pi_i(\boldsymbol{x}))\}_{i=1}^N\big)$$
   其中 $\Pi_i$ 是投影函数，$\mathcal{F}_{\text{view}}$ 是置换不变的聚合网络（IBRNet 中用 DeepSets 结构估计融合权重 $\boldsymbol{w}_i$）
4. **解码**：从聚合特征 $\boldsymbol{f}(\boldsymbol{x})$ 解码出透明度 $\alpha(\boldsymbol{x})$ 和颜色 $\boldsymbol{c}(\boldsymbol{x})$
5. **体积渲染**：沿光线积分合成像素颜色

### 3.2 Lift3D 的关键改动：渲染特征，而不是颜色

Lift3D 的核心洞察：**如果我把 DINO/CLIP 的特征图当成「颜色」来渲染，会发生什么？**

具体做法：

1. **训练时**，对每个多视图场景，用预训练 DINO/CLIP 提取每个视图的**特征图**（不是 RGB）
2. 用 GNVS 管线训练从源视图特征图渲染目标视图特征图——即把上面第 4 步的颜色解码 $\boldsymbol{c}(\boldsymbol{x})$ 换成**特征解码**
3. Loss：渲染出的特征图 vs 真实特征图的余弦相似度

**训练完成后**，渲染器学会了：给定源视图的某种特征图，如何在新视角上 3D 一致地插值这些特征。

### 3.3 Zero-Shot Lifting

这是最妙的部分。对于任意一个**没见过的** 2D 视觉模型 $M$（风格迁移、超分、分割、上色……）：

1. 用 $M$ 的 encoder（或前几层）提取每个源视图的中间特征
2. 把 Lift3D 渲染器当作「特征插值器」——输入源视图的特征图 + 目标位姿，输出目标视角的 3D 一致特征图
3. 把渲染出的特征图喂回 $M$ 的 decoder，得到最终输出

因为 Lift3D **在训练时学到的是「特征如何在 3D 空间中插值」这个通用能力**，而不是某个特定特征空间的模式，所以它能泛化到任何特征空间。

## 4. 架构细节 — §4

- **特征提取器 $\mathcal{F}_{\text{conv}}$** (§4)：沿用 IBRNet 的 2D CNN，不是 DINO/CLIP 本身。DINO/CLIP 只用来生成训练时的 ground truth 特征图
- **特征聚合 $\mathcal{F}_{\text{view}}$**：DeepSets 风格的置换不变网络，估计每个源视图的融合权重（occlusion-aware）
- **渲染**：同 IBRNet — 沿光线采样 64 个点，trilinear interpolation 查特征，alpha compositing 合成
- **损失函数** (§4, Eq. 2)：余弦相似度在特征空间计算
  $$\mathcal{L} = 1 - \frac{\hat{\boldsymbol{F}}_T \cdot \boldsymbol{F}_T}{\|\hat{\boldsymbol{F}}_T\| \|\boldsymbol{F}_T\|}$$
  其中 $\hat{\boldsymbol{F}}_T$ 是渲染出的目标特征图，$\boldsymbol{F}_T$ 是从目标视图真值用 DINO/CLIP 提取的特征图
- **训练数据**：Objaverse + MVImgNet 等多视图数据集
- **训练时的特征模型**：仅 DINO 和 CLIP

## 6. 思考

### 为什么这能 work？

关键跳出了「为每个任务设计 3D 管线」的思维定势。Lift3D 做的其实很简单：**把特征图当成 RGB 来渲染**。几乎所有 2D 视觉模型都可以拆成 encoder → decoder 结构，中间特征图天然有空间对齐性。一旦渲染器学会了在 3D 中插值特征，任何特征空间都可以插。

### 和「单图预测 feature volume」的区别

之前我写的是错的。Lift3D 不是 $\mathcal{F} = \mathcal{G}(I_{\text{ref}})$ 这种单图→体素的映射。它的核心是 **image-based rendering + 体积渲染**，需要多视图输入。这更像 NeRF 而不是 3D 重建。

### 局限

- 需要多视图输入 + 已知位姿（不是单图 3D）
- 渲染质量受限于 GNVS 管线的几何精度（模糊、遮挡、大视角变化时退化）
- 依赖 DINO/CLIP 特征空间的覆盖度，对它们的盲区泛化有限
- 只能处理 encoder-decoder 结构的 2D 模型的特征空间，不是所有 2D 模型都能这样拆
