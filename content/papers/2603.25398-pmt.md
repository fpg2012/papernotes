> **TLDR**: 提出 Plain Mask Decoder (PMD)，在冻结 VFM 编码器上只需 6 层轻量 Transformer decoder 就能复现 EoMT 的 query-patch 联合注意力，匹配 SOTA 冻编模型精度同时快 ~3 倍（图像）和 8 倍（视频）。

## 1. TLDR

- **领域**: 图像/视频分割
- **任务**: 在保持 VFM 编码器**完全冻结**的前提下做高效分割
- **问题**: EoMT/VidEoMT 的 encoder-only 设计虽然快，但需要 finetune 整个 ViT 编码器（因为 query 被注入到编码器内部，冻结编码器时 attention 完全不认识这些新增 token，精度从 52.0 PQ 暴跌到 6.8 PQ），这使得编码器无法在多任务场景下共享
- **核心贡献**: Plain Mask Decoder (PMD)——一个轻量 Transformer decoder，作用在冻结的 ViT 特征上，模拟 EoMT 最后 L₂ 层的行为。图像分割匹配 SOTA 冻编方法（56.1 vs 56.4 PQ），快 ~3 倍；视频分割甚至超过完全 finetune 的模型，快 ~8 倍

## 2. 作者背景

埃因霍温理工大学（TU/e）的视觉计算组。此前曾在 ECCV 等会议上发表图像/视频分割相关工作。

## 3. 相关工作背景

- **Mask Transformer 框架**（Mask2Former 等）：用 query 做 mask classification。通常需要 ViT-Adapter（恢复多尺度特征）+ pixel decoder + Transformer decoder + 多尺度特征融合，速度慢
- **Encoder-only 分割（EoMT/VidEoMT）**：把 learnable query 注入 ViT 的后面几层，patch 和 query 在共享自注意力中处理，去掉 adapter/pixel decoder/multi-scale，速度很快。**但必须 finetune 整个编码器**——冻结时 query 自注意力完全失效
- **冻结编码器分割**（ViT-Adapter + Mask2Former）：编码器冻结，但保留复杂 decoder，精度还行但很慢

**关键差异**：PMT 用轻量 decoder 模拟 EoMT 最后的 joint attention，同时保持编码器冻结，兼顾速度、精度和共享能力

### 🧠 背景：EoMT 是什么？为什么必须 finetune？

**EoMT（Encoder-only Mask Transformer）** (P.3) 的核心洞察是：当 ViT 编码器足够大、预训练足够充分时，传统分割 pipeline（adapter + pixel decoder + Transformer decoder + multi-scale）中的大部分模块其实是多余的。

**EoMT 怎么做？**

标准 ViT 有 $L$ 层，EoMT 把它切成两段：
- 前 $L_1$ 层：正常处理 patch tokens
- 在第 $L_1$ 层之后：把 $K$ 个 learnable query $\mathbf{Q}^{\mathrm{lm}} = \{\mathbf{q}_{\mathrm{i}}^{\mathrm{lm}} \in \mathbb{R}^{D}\}_{i=1}^{K}$ **直接拼接到 patch token 序列后面**
- 后 $L_2$ 层：patch 和 query 作为一个序列一起过 MHSA + FFN

关键在最后 $L_2$ 层：由于所有 token（patch + query）互相做 full attention，**一个 MHSA 操作同时完成了三件事**：
1. query 互相注意（query self-attention）
2. query 注意 patch（query-to-patch attention）
3. patch 注意 query（patch-to-query attention）

这替代了传统方法中显式的 cross-attention decoder，大大简化了架构。每个 ViT layer 的标准计算：

$$\begin{aligned}\mathbf{Z}^{l}&=\mathbf{X}^{l}+MHSA\big(\mathrm{Norm}(\mathbf{X}^{l})\big),\\\mathbf{X}^{l+1}&=\mathbf{Z}^{l}+\mathrm{FFN}\big(\mathrm{Norm}(\mathbf{Z}^{l})\big).\end{aligned}$$

**为什么快？** 没有独立的 adapter、pixel decoder、multi-scale fusion，推理时经过 mask annealing 后可用 FlashAttention。对比 ViT-Adapter + Mask2Former 的 48 FPS，EoMT 达到 162 FPS。

**为什么必须 finetune 整个编码器？** 这是 EoMT 的核心限制，也是 PMT 要解决的核心问题。

预训练好的 ViT attention 层**从未见过 query token**。当 $L_2$ 层第一次看到拼接进来的 query 时，那些预训练好的 QKV 投影权重不知道该怎么处理它们——它们只对 patch token 之间的 attention 做过优化。冻结编码器时，query 对 patch 的 attention 和 patch 对 query 的 attention 都是完全随机的，结果 query 学不到任何有意义的表征。

论文 Table 1 直观证实了这一点：逐步删减 M2F 组件到 EoMT 冻结配置时，PQ 从 52.0 直接跌到 **6.8**——这不是精度下降，是**完全崩塌**。这就是 PMT 必须把 query 处理**移出编码器**的根本原因。

## 4. 核心方法

### 4.1 问题形式化

给定冻结的 ViT 编码器 φ 和输入图像 I：
- 编码器输出 patch tokens Xᴸ ∈ ℝᴰ ˣ ᴺ（N = H/p × W/p 个 patch）
- 目标是预测 K 个 query 的类别 cᵢ 和 mask Mᵢ

### 4.2 PMT 架构 **(Figure 2, P.4)**

**核心洞察**：EoMT 最后 L₂ 层做的事情本质上是 query + patch 的 joint attention。这个可以用一个**独立的小 decoder** 做，不需要动编码器。

**Plain Mask Decoder (PMD)** **(P.4)**：
- 6 层标准 Transformer layer（与 DINOv3 编码器层结构一致：相同 hidden dim、head 数、FFN）
- K 个 learnable query + N 个 patch token 拼接成一个序列，过 MHSA（所有 token 互相注意）
- 等价于 EoMT 的 joint query-patch attention，但权重是**随机初始化、独立训练**的，不依赖预训练编码器
- 输出：query 做 class 预测（线性层），patch tokens 做 mask 预测（reshape + 上采样后与 query 点积）

**Lateral Connections（横向连接）**(P.4-5)：
- 从编码器均匀间隔的层抽取中间层 patch token（包括最后层 L）
- 按 DINOv3 策略归一化（最后层的 LayerNorm + 可训练的 BatchNorm）
- 两层 MLP 投影后 element-wise 求和，形成多尺度特征输入 decoder
- 弥补冻结编码器无法自适应目标任务的不足

**RoPE**：给 decoder 的 patch token 加 RoPE（query 不加，保持 permutation invariance）

### 4.3 视频扩展 **(P.5)**

直接复用 VidEoMT 的 query 传播机制 **(P.4)**：
- $t=0$：用 learnable query $\mathbf{Q}^{\mathrm{lm}}$
- $t>0$：前一帧的 output query $\mathbf{Q}_{t-1}$ 与 learnable query $\mathbf{Q}^{\mathrm{lm}}$ 融合后输入 decoder：

$$\mathbf{Q}_{t}^{\mathcal{F}}=\mathrm{Linear}(\mathbf{Q}_{t-1})+\mathbf{Q}^{\mathrm{lm}}$$

- 无需 tracker / re-identification / temporal transformer

### 4.4 Mask Annealing（掩码退火）——你问的"退火"

**为什么需要掩码？**

在 EoMT 的训练中，每个 decoder layer 都使用 **masked attention**：根据当前 query 预测的中间 mask，限制 query 只关注自己预测区域内（前景）的 patch token，忽略背景区域。这会强制 query 聚焦到特定物体上，**加速训练收敛**。

**为什么要退火？**

Masked attention 有两个关键缺点：
1. 推理时每层预测中间 mask 的计算开销很大，层数多了可能**翻倍延迟**
2. Masked attention 是自定义 attention pattern，**不兼容 FlashAttention**——FlashAttention 要求标准 unmasked dense attention

**Mask Annealing 怎么做？**

所谓"退火"（annealing），就是在训练过程中**逐步减小 masked attention 的力度**，直到完全移除：

- 训练初期：完全使用 mask attention（快速收敛）
- 训练中期：逐渐降低 mask 的强度，让 query 慢慢学会不依赖 mask 也能正确聚焦
- 训练末期：mask 完全消失，模型只使用标准 unmasked dense attention

这样训练出来的模型**推理时不需要任何 mask**，可以：
- 使用 FlashAttention → 延迟降为原来的一半
- 去掉每层中间 mask 预测 → 加速显著

**和物理退火的类比**：很像材料科学里的退火——先加热（用 mask 强约束），再慢慢降温（逐步移除 mask），让系统"固化"到最优状态。

## 5. 实验

### 5.1 实验设置

- **数据集**：COCO（全景/实例）、ADE20K（语义）、YouTube-VIS 2019/2021（视频实例）、VIPSeg（视频全景）、VSPW（视频语义）
- **编码器**：DINOv3-L 为主（patch=16，分辨率 640²）
- **训练**：AdamW，mask annealing，6K 线性 warmup
- **指标**：PQ/mIoU/AP（图像），AP/VPQ/mIoU（视频）
- **推理**：H100 + FlashAttention-2 + torch.compile

### 5.2 主要结果

**图像分割 (Table 6, P.6)**：
- PMT (DINOv3, 640²): 56.1 PQ, 141 FPS
- ViT-Adapter + M2F (冻结): 56.4 PQ, 48 FPS → **PMT 速度 ~3×**
- EoMT (finetune): 56.8 PQ, 162 FPS → PMT 仅差 0.7 PQ，但编码器是**冻结的**

**视频实例分割 (Table 8, P.7)**：
- PMT (DINOv3): 69.2 AP, 113 FPS
- CAVIS (冻结): 68.8 AP, 13 FPS → **PMT 速度 ~8×，精度还更高**
- VidEoMT (finetune): 68.9 AP, 133 FPS → PMT **冻结编码器 > finetune 编码器**

**视频语义分割 (Table 10, P.8)**：
- PMT (DINOv3): **65.7 mIoU** — 新 SOTA，全方法中最高

### 5.3 消融 (Table 2, Table 5)

- 冻结 EoMT → 6.8 PQ（完全崩塌）；+ PMD → 53.7 PQ；+ lateral → 55.9 PQ；+ RoPE → **56.1 PQ**
- 6 层 decoder 是最优性价比（Table 5）
- 预训练规模越大 PMT 越好（Table 3）：DINOv3 > DINOv2 >> IN21K >> IN1K

### 5.4 可能的不足

- 需要大规模预训练编码器（DINOv3），小模型效果不佳
- VPS 任务上精度仍略低于复杂 decoder
- GAB（另一个工作中的概念）与 RoPE 的选择未被充分探讨

## 6. 一句话总结

PMT 用 6 层轻量 decoder 在冻结的 VFM 编码器上完美解耦了 encoder-only 分割的速度优势和编码器共享的实际需求，图像 3× 视频 8× 的速度提升让人印象深刻。

## 🧠 Sidenote: 为什么要有 Mask Annealing（掩码退火）？

### 背景

EoMT/PMT 在训练中使用 **masked attention**：每层 decoder 根据当前 query 预测的中间 mask，让 query 只关注自己预测区域内的 patch token（前景），忽略背景。这强制 query 快速聚焦到物体上，加速早期训练收敛。

### 问题

但 masked attention 有两大硬伤：
1. 推理时每层都要**额外算中间 mask**，计算量几乎翻倍
2. **自定义 attention pattern 不兼容 FlashAttention**，后者是加速推理的关键

### 退火过程

Mask Annealing 在训练**逐步移除** masked attention：

```
训练进度  →  0% [完全 mask] ── 50% [逐渐减弱] ── 100% [无 mask]
                                                        ↓
                                             推理时零开销 ← 兼容 FlashAttention
```

具体做法：引入一个退火系数 α 从 1 线性衰减到 0，控制 mask 的影响程度。α=1 时完全使用 masked attention，α=0 时只用 unmasked attention。

### 为什么有效

直观理解：masked attention 像**训练用的拐杖**。一开始没有它 query 不知道往哪看，模型不收敛。但训练到后期 query 已经学会了正确关注哪些区域，就不需要 mask 来"指路"了——此时移除 mask 不会影响性能，反而释放了 FlashAttention 的加速能力。

### 类比：物理退火

| 退火 | 材料科学 | Mask Annealing |
|------|---------|----------------|
| 高温 | 原子活跃，可重新排列 | 训练初期，mask 让 query 自由探索 |
| 降温 | 原子逐渐固定位置 | mask 逐渐移除，query 学会自主聚焦 |
| 常温 | 晶体结构固化 | 无 mask，模型已学会最佳 attention pattern |
