## TLDR

**领域**: 多模态 / VLM 效率优化 / 视觉 Token 压缩

**任务**: 将 VLM 中 576 个视觉 patch token（来自 ViT-L/14）压缩到 1 个 token，同时保持语义（物体类别、空间关系）和细节（纹理、姿态）信息。

**问题** (P.1-2)：576 个 patch token 喂入 LLM → 自注意力 $\mathcal{O}((N+L)^2)$ → 显存和上下文窗口压力巨大。但压缩面临两难：
- **连续压缩**（pooling, Q-Former, VoCo-LLaMA）：将 576 patches 坍缩为单个连续向量 → 语义被"稀释"，互信息 $I(v_c; S) \to 0$（例：狗和猫的 patch 被平均后无法区分物种）
- **离散量化**（VQ-VAE, MGVQ）：用 codebook 保存语义模式 → 丢失细粒度连续信息，量化噪声 $\epsilon = f(I) - c_k$ 消除纹理差异（例：草地上的金毛和沙地上的贵宾映射到同一个 code）

**核心贡献** (P.2)：
1. **表征分析**：指出纯连续单 token 瓶颈无法同时编码离散语义和连续细节
2. **混合解耦框架**：在压缩前注入最少离散语义锚点，实现语义和外观分离后再融合
3. **HTC-VLM 实例化**：580-to-1 压缩比下 87.2% 平均性能保留率，超 VoCo-LLaMA（81.0%）6.2 个百分点

## 3. 相关工作

VLM token 效率方法分三类，HTC-VLM 站在它们的交叉点上 (P.2)：

**Token 缩减方法**（ToMe, FastV, PDrop, SparseVLM）：在连续特征空间里做 token merging/patch dropping/冗余选择。非极端压缩（192/128 tokens）效果好，但极端压缩（1-4 tokens）下连续特征坍缩。

**连续压缩**（Q-Former, Avg. Pool, VoCo-LLaMA）：将 patches 映射为单个密集向量。VoCo-LLaMA 用 `<voco>` token 做 bottleneck。问题是语义稀释（semantic dilution）。

**离散压缩**（VQ-VAE, MoVQ, MGVQ）：产生紧凑可解释的 code，保持高层语义但丢弃连续外观变化。问题是粒度损失（granularity gap）。

**HTC-VLM 定位**：在极端压缩（1 token）场景下，显式将视觉信息解耦为离散语义通道 + 连续细节通道，通过 disentanglement mask 和 bottleneck 融合。

## 4. 核心方法

### 4.1 问题形式化 (P.3)

VLM 建模条件分布 $p_\theta(Y \mid I, T)$：图像 $I$ 和文本指令 $T$ 生成回答 $Y$。先用视觉编码器 $\mathcal{E}_v$（CLIP ViT-L/14）提取 576 个 patch embedding，经线性投影器 $\mathcal{P}_v$ 映射到 LLM 嵌入空间：

$$ V = \{v_1, \ldots, v_{576}\} = \mathcal{P}_v(\mathcal{E}_v(I)), \quad V \in \mathbb{R}^{576 \times d_{\text{model}}} $$

$d_{\text{model}} = 4096$。自注意力复杂度 $\mathcal{O}((N + L)^2)$，单层运算 $1.07 \times 10^9$ FLOPs。

压缩目标：找到最优压缩器 $\mathcal{C}^* = \arg\min_{\mathcal{C}} \mathbb{E}_{(I,T,Y) \sim \mathcal{D}}[\mathcal{L}(Y, \text{VLM}(T, \mathcal{C}(\mathcal{E}_v(I))))]$

### 4.2 架构

*Figure 2 (P.3)：三种 token 压缩策略对比。(a) Pooling (b) VoCo-LLaMA (c) HTC-VLM（本文）*

**连续通道：编码低层细节 $D$** (P.3)

576 个 patch embeddings：$V = \{v_i\}_{i=1}^{576} = \mathcal{P}_v(\mathcal{E}_v(I))$，保留纹理梯度、姿态变化等细粒度信息。

**离散通道：编码高层语义 $S$** (P.3)

用 MGVQ（多组向量量化，8 groups, 16384 codebook size, 16× downsampling）将图像 $I$ 量化到 $q \in \mathbb{R}^{14112}$，通过两层 MLP 投影到离散 embedding $v_d \in \mathbb{R}^{4096}$：

$$ q = \mathcal{Q}(I), \quad v_d = \mathcal{P}_d(q) = \text{GELU}(W_2 \cdot \text{GELU}(W_1 \cdot q)) $$

其中 $W_1 \in \mathbb{R}^{8192 \times 14112}, W_2 \in \mathbb{R}^{4096 \times 8192}$。

**融合与解耦瓶颈** (P.3-4)

混合序列：$V_{hy} = [v_d; V] \in \mathbb{R}^{580 \times 4096}$（4 个离散 token + 576 连续 token = 实际上是 1+576=577... 等等，原文说 4 个 semantic tokens，但 $v_d$ 只有一个。让我再看一下。）

$V_{hy} = [v_d; V] \in \mathbb{R}^{580 \times 4096}$，加上 trainable $\langle voco \rangle$  token。解耦注意力掩码 $M_{hy}$：

$$ M_{hy}(i,j) = \begin{cases}
0, & \text{if } x_i \in W \text{ and } x_j \in V_{hy} \\
-\infty, & \text{if } x_i,x_j \in V_{hy} \text{ and } i \neq j \\
1, & \text{otherwise}
\end{cases} $$

其中 $X = [V_{hy}; \langle voco\rangle; W]$，$W$ 为文本 token。该 mask 确保：
- 文本 token 只能关注 $\langle voco\rangle$，不能看到 $V_{hy}$
- $V_{hy}$ 内部 token 互相不可见（自注意力被禁止）
- $\langle voco\rangle$ 可以关注 $V_{hy}$ 中的所有 token

这迫使 $\langle voco\rangle$ token 将所有视觉信息压缩到单个 latent $z$ 中。

### 4.3 训练目标 (P.4)

自动回归损失：

$$ \mathcal{L}_{\text{HTC}} = -\mathbb{E}_{p(I,T,Y)}\left[\sum_{i=1}^{|Y|} \log p_\theta(y_i \mid y_{<i}, \langle voco\rangle, T; M_{hy})\right] $$

等价于变分下界（ELBO）：

$$ \mathcal{L}_{\text{HTC}} \approx -\mathbb{E}_{q(z \mid V_{hy})}[\log p(Y \mid z, T)] + KL(q(z \mid V_{hy}) \| p(z)) + \text{const} $$

其中 $q(z \mid V_{hy}) = p(\langle voco\rangle \mid V_{hy}; \theta)$，$p(z) \sim \mathcal{N}(0, I)$。

## 5. 实验

### 5.1 实验设置 (P.4)

严格遵循 VoCo-LLaMA 设置。7 个 benchmark：GQA, VQAv2, MMBench, MME, POPE, SEED-Bench, ScienceQA-Image。Upper Bound = 无压缩的 576 token 原始 VLM，Lower Bound = 单 token 压缩而不训练。

### 5.2 主要结果

**Table 1** (P.4)：580-to-1 极端压缩

| 方法 | 压缩方案 | 平均保留率 |
|------|:--------:|:----------:|
| Q-Former | 1 连续 token | 57.2% |
| Avg. Pool | 1 连续 token | 64.1% |
| VoCo-LLaMA | 1 连续 token | **81.0%** |
| **HTC-VLM** | **1 hybrid token** | **87.2%** |

HTC-VLM 在 7 个 benchmark 上全部超过 VoCo-LLaMA（ScienceQA-Image 上甚至达到 120.7% retention，说明压缩后性能反超无压缩基线）。

**Table 2** (P.5-6)：多 token 预算（192/128/64 tokens）

- 192/128 tokens 时 HTC-VLM 与 SparseVLM、PDrop 竞争力相当（94.2%/93.8%）
- **64 tokens 时 HTC-VLM 89.8% retention 显著优于所有方法**（SparseVLM 89.3%, VoCo-LLaMA 89.6%, 其余更低）

**Representation Probing** (Table 3, P.6)：在 776 个样本上对三种中间表征做线性探针：
- $z_{voco}$（混合压缩后）：Detail 任务 30.70%，Semantic 任务 26.67%，两项最高
- $v_d$（离散通道）：信息更紧凑（4 tokens），两项均弱于 $z_{voco}$ 但仍有解码能力
- $\bar{V}$（连续通道平均）：Detail 27.19%，Semantic 26.67%
- **结论：$z_{voco}$ 成功融合了两者的优势**

**Attention 分析** (P.6)：压缩后的 $\langle voco\rangle$ token 注意力权重主要分配给离散语义 token，验证了其语义引导作用。

### 5.3 可能的不足

- 训练数据、backbone 严格跟随 VoCo-LLaMA，缺乏独立设置的消融
- 离散通道需要外部的 MGVQ 模型，增加了训练/推理的复杂度
- 在 192/128 token 预算下并不领先于 token merging 方法，仅极端压缩下显优势
- 缺乏 CheXpert 等专业领域 VLM benchmark 的验证

## 一句话总结

HTC-VLM 证明了在极端视觉 token 压缩前用离散语义锚点进行语义-细节解耦，可以在 580-to-1 压缩比下达到接近无损的性能（87.2%）。
