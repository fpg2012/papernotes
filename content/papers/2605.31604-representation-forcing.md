> **TLDR**: 提出 Representation Forcing (RF) 技术，让统一多模态模型在无需预训练 VAE 的情况下实现像素空间图像生成，通过迫使解码器自回归地预测视觉表征作为中间 token，再将 token 保留在上下文中指导像素扩散，在生成和理解任务上均达到或超越基于 VAE 的基线模型。

## 1. 作者背景

本文由香港大学（Yuqing Wang, Xihui Liu）与字节跳动 Seed 团队（Zhijie Lin, Ceyuan Yang, Yang Zhao, Fei Xiao, Qi Zhao, Zihan Ding, Haoqi Fan 等）合作完成，合作者还包括香港中文大学、南京大学和清华大学的学生 **(P.1)**。字节跳动 Seed 团队此前在统一多模态预训练领域有重要工作（BAGEL [10]），本文基于 BAGEL 的 MoT 架构继续推进像素空间（pixel-space）的统一多模态建模。

## 2. 相关工作背景

本文站在三条研究线的交叉点上：

- **统一多模态模型（UMMs）**：现有 UMMs 分为两类——第一类在单一 backbone 内生成，将图像建模为离散 token（Chameleon [4]、Emu3 [46]）或 在 VAE 潜在空间附加扩散（Transfusion [60]、Show-o [52]、JanusFlow [31]、BAGEL [10]），但**全部依赖一个单独预训练的视觉 tokenizer（VQVAE 或连续 VAE）**；第二类将 LLM 与外部扩散模型拼接（Emu2 [41]、SEED-X [18]、BLIP3-o [5]、MetaQueries [35]）。本文的 RF 消除了对预训练 VAE 的依赖 **(P.3)**。

- **像素空间生成**：近期工作（JiT [27]、PixelFlow [7]、SiD2 [22]）表明像素级扩散在独立生成模型上可行，但在 UMMs 中，更广的图像分布和更丰富的文本条件信息使朴素像素扩散存在明显的质量差距 **(P.3)**。

- **生成中的表征学习**：REPA [55] 对齐扩散中间特征与预训练表征以加速收敛；RAE [42, 59] 用冻结的 DINOv2/SigLIP 编码器替代 VAE。但这些方法仍在冻结的、外部定义的表征空间中运行 **(P.4)**。RF 与之不同：解码器直接从自身联合训练的理解编码器预测视觉表征，使高层视觉结构成为生成过程的内生输出。

## 3. 核心方法

### 3.1 问题形式化

统一多模态模型旨在单一 backbone 中完成：

- **理解**（文本输出）：标准的 next-token prediction，输入图像 → 视觉编码器提取特征 → 与文本 token 拼接 → 自回归解码
- **生成**（像素输出）：给定文本 prompt → 在共享 backbone 中执行扩散生成图像

**现有方案的问题**：生成通路依赖一个冻结的、单独预训练的 VAE（如 WanX-2.1 VAE），图像先被压缩到潜在空间再进行扩散，然后用固定解码器恢复像素 **(P.2, Figure 1a)**。这种潜在空间针对重建而非 UMM 目标优化，产生无法通过进一步训练克服的质量瓶颈。

**本文目标**：消除 VAE 依赖，在像素空间中直接生成，同时不损失生成质量。

### 3.2 模型/方法架构

#### Representation Forcing (RF) 核心思想

RF 的关键洞察：UMMs 的理解通路已经提供了捕捉高层结构（物体身份、空间布局、场景构成）的视觉表征；在生成时，解码器需要从文本输入**预测**这些表征，而非从图像中提取 **(P.2-3)**。

![](/papers/figures/2605.31604-fig1.jpg)

**Figure 1** (P.2)：架构对比。(a) 现有 UMMs 依赖冻结 VAE；(b) 朴素移除 VAE 后缺乏结构指导；(c) RF 通过让解码器预测视觉表征作为中间 token 来消除质量差距。

#### 表征的来源与离散化 **(P.4-5)**

- 使用 EMA（指数移动平均）版本的 DINOv3 ViT-H+/16 视觉编码器提取 patch 级特征（最后一层、final norm 之前）
- 通过**在线向量量化**（online vector quantization）将这些连续特征离散化为表征 token：维护 K=16,384 个可学习的原型嵌入（codebook），每个 patch 特征被分配到 cos 相似度最近的原型
- 使用 Sinkhorn-Knopp 平衡来防止 codebook collapse
- 2×2 pooling：每 4N 个像素 patch 对应 N 个表征 token，按 raster-scan 顺序排列
- Codebook 通过动量更新（decay=0.9999，参照 SwAV [3]）

#### Token 序列与注意力机制 **(P.5-6)**

序列结构：`[文本 tokens, 表征 tokens, 像素 patches]`

注意力模式：
- 文本 token 和表征 token：causal attention（标准自回归）
- 噪声像素 patches：互相双向 attention，对前面所有文本和表征 token 做 casual attention
- 这种设计使表征 token 充当 **in-context conditioning**——高层结构通过标准 self-attention 流入像素生成，无需额外的 cross-attention 或注入模块

#### 架构 **(P.5-7)**

- **Backbone**：Mixture-of-Transformers (MoT)，初始化自 Qwen3-A3B（3B 激活参数/token）
- **三个 FFN expert 组**：multimodal understanding、representation token prediction、pixel generation
- **图像编码器**：DINOv3 ViT-H+/16，支持 NaViT 变分辨率
- **像素 patch 大小**：16×16
- **生成方式**：x-prediction with velocity loss（参照 JiT [27]）

#### 损失函数 **(P.6)**

$$\mathcal{L} = \mathcal{L}_{\mathrm{LM}} + \mathcal{L}_{\mathrm{FM}} + \mathcal{L}_{\mathrm{Rep}}$$

其中：
- $\mathcal{L}_{\mathrm{LM}}$：文本 next-token prediction 的交叉熵损失
- $\mathcal{L}_{\mathrm{Rep}}$：表征 token prediction 的交叉熵损失
- $\mathcal{L}_{\mathrm{FM}}$：像素生成的 flow-matching 损失

噪声 patch：$\mathbf{z}_{t} = t\mathbf{x} + (1 - t)\boldsymbol{\epsilon}, \quad t \in [0,1]$

Flow-matching 损失：$\mathcal{L}_{\mathrm{FM}} = \mathbb{E}\big\|\mathbf{v}_{\theta} - \mathbf{v}\big\|^{2}$

其中 $\mathbf{v} = \mathbf{x} - \epsilon$，$\mathbf{v}_{\theta} = (\mathbf{x}_{\theta} - \mathbf{z}_{t}) / (1 - t)$

训练时独立以 0.1 概率 drop text 条件和表征 token 序列，以支持 inference 时的 classifier-free guidance。

#### 推理过程 **(P.6)**

两阶段生成：
1. 解码器从文本 prompt 开始自回归生成完整的表征 token 序列
2. 以文本和预测的表征 token 为条件，从高斯噪声执行 25 步 flow-matching 迭代去噪，直接在像素空间合成最终图像
3. CFG 权重：$w_{rep}=2.0$（表征 token 采样），$w_{pix}=3.0$（像素去噪）

### 3.3 训练策略 **(P.7)**

三阶段训练（参照 BAGEL [10]）：

| 阶段 | 冻结部分 | 分辨率 | 迭代数 | LR |
|------|----------|--------|--------|-----|
| Stage 1: Alignment | backbone + 编码器 | — | 10K | $5 \times 10^{-5}$ |
| Stage 2: Joint Pre-training | 无 | ≤256 | 50K | $5 \times 10^{-5}$ |
| Stage 3: Continued Training | 无 | ≤1024 | 20K | $2.5 \times 10^{-5}$ |

主要优化器设置：AdamW ($\beta_1=0.9$, $\beta_2=0.95$, weight decay=0.1, gradient clipping=1.0)
新增生成相关参数使用 base LR 的 4× 倍率，LLM backbone 保持 base LR。
NaViT 变分辨率 packing，每个 GPU 处理 32,768 tokens 的序列。

训练总目标 + 训练流程见下图：

## 4. 实验

### 4.1 实验设置

**数据集**：遵循 BAGEL [10] 的数据构建和过滤流程，使用混合数据：(1) 纯文本数据；(2) 大规模文本-图像对（覆盖图像→文本理解的通用 VQA、文档理解、空间推理；文本→图像生成）

**评估指标**：
- **生成**：GenEval [19]（组合生成, 6个子维度 + Overall），DPG-Bench [23]（密集 prompt 遵循）
- **理解**：MMMU [56]，HallusionBench [20]，MME [15]，BLINK [16]，RealWorldQA [51]（通用视觉理解）；AI2D [24]，DocVQA [33]，ChartQA [32]（文档/图表理解）

**Baselines**：控制变量——四组变体（Pixel, Pixel+RF, VAE, VAE+RF），仅生成通路不同，架构、数据、优化完全一致。VAE 使用 WanX-2.1 VAE [47]。

### 4.2 主要结果

#### 生成 (Table 1, P.7)

- **RF-Pixel (ours)**：GenEval Overall = **0.84**（无 LLM rewriter）, **0.88**（有 LLM rewriter）
- 无 rewriter 时超越 BAGEL (0.82)，匹配 BLIP3-o (0.84)
- 有 rewriter 时匹配 SOTA 统一模型（BAGEL† 0.88）
- DPG-Bench：84.15，与 VAE-based 统一模型相当
- 关键意义：**首次在无任何预训练 VAE/VQVAE 的情况下，像素空间统一模型达到 VAE-based SOTA 水平**

#### 理解 (Table 2, P.8)

- RF 在两种生成通路下均一致提升理解性能
- **Pixel+RF** 改善 6/8 个 benchmark：
  - MMMU: +4.3 (49.9→54.2)
  - MME: +3.6 (76.6→80.2)
  - BLINK: +3.6 (49.4→53.0)
  - AI2D: +4.5 (85.8→90.3)
  - RealWorldQA: +2.7 (63.1→65.8)
  - 轻微下降仅在 DocVQA (-2.0) 和 ChartQA (-0.4)
- **Pixel+RF 在 6/8 个 benchmark 上超越 VAE+RF**，说明像素空间生成更有利于统一多模态建模

#### 定性结果 (Figure 4, P.10)

**Figure 4** (P.10)：像素空间生成有无 RF 的定性对比。无 RF 时图像结构混乱、物体变形；加 RF 后结构高度连贯。

### 4.3 消融实验 (Table 3, P.9)

**a) RF 对两种生成通路的效果 (Table 3a)**

| | Pixel | VAE |
|---|---|---|
| w/o RF | 0.25 | 0.52 |
| w/ RF | **0.76** | **0.77** |

RF 对像素空间的效果尤为显著（+0.51），接近 VAE-based 水平。

**b) 解码器预测 vs. 辅助对齐 (Table 3b)**

| Method | GenEval |
|--------|---------|
| w/o guidance | 0.25 |
| REPA (auxiliary alignment) | 0.43 |
| RF (decoder prediction, ours) | **0.76** |

RF 大幅超越 REPA。作者推测原因：REPA 的对齐特征不显式条件化生成输出；RF 将预测表征直接放入序列，像素 patch 通过 shared self-attention 关注它们，在高维像素空间中直接条件化更有效。

**c) 离散 vs. 连续表征 (Table 3c)**

| Formulation | GenEval |
|-------------|---------|
| Continuous regression | 0.26 |
| Discrete tokens | **0.76** |

两个原因：(1) 因果预测高维连续向量容易误差累积；(2) 离散化自然鼓励表征保留高层结构、丢弃细粒度细节。

**d) Codebook 大小 (Table 3d)**
K=16,384 (0.76) vs K=32,768 (0.77)——不敏感，使用 K=16,384。

**e) 理解编码器选择 (Table 3e)**
DINOv3 在 4/5 benchmark 上优于 SigLIP2，因其自监督目标产生空间和结构更丰富的特征。

### 4.4 实验可能的不足

- **从预训练 LLM 初始化**：模型从 Qwen3-A3B 而非从头训练，完全的从头多模态预训练可能产生更丰富的联合表征 **(P.10, Limitations)**
- **仅限静态图像**：未扩展到视频或其他时序模态 **(P.10)**
- **3B 模型规模**：与更大规模模型（如 7B+）的对比有待验证（BAGEL 在更大规模下取得了更高分数）
- **DocVQA/ChartQA 轻微下降**：RF 对需要精确文本识别的任务提升有限，暗示还需专门设计以支持 OCR

## 5. 一句话总结

Representation Forcing 通过让统一多模态模型的解码器自回归预测来自自身理解编码器的离散视觉表征，在无需任何预训练 VAE 的情况下实现了像素空间图像生成，同时提升理解和生成性能，是迈向端到端瓶颈无关统一多模态模型的重要一步。

## 🧠 Sidenote: Online Quantization & Sinkhorn-Knopp 平衡

本文使用 **Online Vector Quantization** 将视觉特征编码为离散 token 序列，而非传统预训练 VAE 的连续 latent。其核心挑战是 **codebook collapse（代码本崩塌）**：训练中模型倾向只使用 codebook 中的少数几个条目，其余条目从未被选中，表征多样性退化。

设 codebook 有 $K$ 个条目 $\{e_1, ..., e_K\}$，每个图像 patch $z$ 被映射到最近的条目：$z_q = e_k$ 其中 $k = \arg\min_i \|z - e_i\|$。训练采用 straight-through estimator 传梯度。崩塌时，实际被选中的 $k$ 集中在很小的子集 $S \subset \{1..K\}$，$|S| \ll K$，其余条目收不到梯度。

**Sinkhorn-Knopp 平衡**通过一个可微分的分配约束解决此问题。对于 batch 中 $N$ 个 patch 到 $K$ 个 codebook 条目的相似度矩阵 $S \in \mathbb{R}^{N \times K}$，交替进行行归一化和列归一化：

$$\tilde{S}_{ij} = \frac{S_{ij}}{\sum_j S_{ij}}, \quad \hat{S}_{ij} = \frac{\tilde{S}_{ij}}{\sum_i \tilde{S}_{ij}}, \quad \text{repeat until convergence}$$

最终得到双随机矩阵（doubly stochastic）：每行和为 1（每个 patch 有一个有效分配）、每列和为 $N/K$（每个 codebook 条目被选中的次数**均衡**）。训练时用均衡后的 $\hat{S}$ 替代原始相似度做 argmax，迫使模型均匀使用所有 codebook 条目。

这比简单加 entropy penalty 更有效：Sinkhorn-Knopp 在保持原始相似度相对排序的前提下显式约束分配均匀性，而非软性惩罚。结果 codebook 利用率从崩塌态的 $\sim 5\%$ 提升到 $> 90\%$，端到端训练稳定。
