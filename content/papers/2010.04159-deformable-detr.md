> **TLDR**: DETR 收敛慢的原因在于 attention 初始化时均匀关注所有像素→梯度模糊。Deformable DETR 让每个 query 只关注参考点附近 K 个采样点（K=4），复杂度从 O(H²W²) 降至 O(HW)，COCO 上 50 epoch 达到 DETR 500 epoch 的性能（AP 43.8 vs 43.3），小物体提升显著（APS 26.4 vs 22.5）。

## 1. TLDR

- **领域**: 目标检测（End-to-End Object Detection）
- **任务**: 解决 DETR 收敛慢、小物体检测差、高分辨率特征图复杂度高的问题
- **问题**: DETR 的 Transformer attention 在初始化时近乎均匀关注所有像素 → 梯度模糊 → 需要 500 epoch 训练。同时 self-attention 复杂度 O(H²W²)，无法处理高分辨率特征图 → 小物体检测差
- **核心贡献**: Deformable Attention——每个 query 只关注参考点附近 K 个**可学习的采样点**（K=4），不关注全图。复杂度降为 O(HW)，支持多尺度特征，50 epoch 达到 DETR 500 epoch 的 AP

## 2. 作者背景

商汤研究院（SenseTime Research）主导（Jifeng Dai），合作方包括中科大（USTC）和港中文（CUHK）。Dai 等也是 Deformable Convolution (Dai et al., ICCV 2017) 的原作者。ICLR 2021 发表。

## 3. 相关工作背景

**DETR (Carion et al., 2020)**：第一个真正的端到端检测器，用 Transformer encoder-decoder + 匈牙利匹配代替 anchor / NMS 等手工组件。但收敛极慢（500 epoch），小物体差。

**DETR 为什么收敛慢？**（论文 Sec 3, P.4）：
- 初始化时，$U_m z_q$ 和 $V_m x_k$ 的分布均值≈0、方差≈1
- 当 key 数量 $N_k$ 很大时，attention 权重 $A_{mqk} \approx 1/N_k$ → **均匀分布**
- 均匀 attention 对所有位置的梯度几乎相同 → 梯度模糊 → 训练很久 attention 才能聚焦到特定区域
- 图像特征图的 $N_k = HW$ 非常巨大 → 问题更严重

**高效 Attention 的三种路线**（Sec 2）：
1. 预定义局部窗口（Swin Transformer 等）→ 丢失全局信息
2. **数据依赖的稀疏 attention**（LSH、k-means）→ Deformable DETR 属于此类
3. 低秩近似（Linformer 等）

**多尺度特征**：FPN、PANet、NAS-FPN 等。Deformable DETR 不需要 FPN——多尺度 deformable attention 天然实现跨尺度信息交换。

## 4. 核心方法

### 4.1 核心问题回顾

标准 Multi-Head Attention（Sec 3）：

$$\text{MultiHeadAttn}(z_q, x) = \sum_{m=1}^M W_m \left[ \sum_{k \in \Omega_k} A_{mqk} \cdot W'_m x_k \right]$$

$$A_{mqk} \propto \exp\left\{ \frac{z_q^T U_m^T V_m x_k}{\sqrt{C_v}} \right\}, \quad \sum_{k} A_{mqk} = 1$$

复杂度 O(N_q C² + N_k C² + N_q N_k C)，在图像上 N_q = N_k = HW → O(H²W²C)。

### 4.2 Deformable Attention (P.5, Figure 2)

**核心公式**：

$$\text{DeformAttn}(z_q, p_q, x) = \sum_{m=1}^M W_m \left[ \sum_{k=1}^K A_{mqk} \cdot W'_m x(p_q + \Delta p_{mqk}) \right]$$

其中：
- $z_q$: query 特征
- $p_q$: 2D 参考点坐标
- $\Delta p_{mqk} \in \mathbb{R}^2$: 第 m 个 head、第 k 个采样点的**可学习偏移量**（由 query 特征通过线性层预测）
- $A_{mqk}$: attention 权重（归一化后 $\sum_k A_{mqk} = 1$，也由 query 特征预测）
- $K$: 采样点数（默认 K=4），$K \ll HW$

**实现细节**：query 特征 → 线性层 (3MK 通道) → 前 2MK 通道做 sigmoid 得采样偏移 $\Delta p$，后 MK 通道做 softmax 得注意力权重 $A$。分数坐标用双线性插值。

**复杂度**：O(2N_q C² + min(HWC², N_q KC²))
- Encoder 中 N_q = HW → O(HWC²) ✨ **线性复杂度**
- Decoder cross-attention 中 N_q = N（object queries）→ O(NKC²) ✨ **与特征图大小无关**

### 4.3 Multi-Scale Deformable Attention (P.5-6)

$$\text{MSDeformAttn}(z_q, \hat{p}_q, \{x^l\}_{l=1}^L) = \sum_{m=1}^M W_m \left[ \sum_{l=1}^L \sum_{k=1}^K A_{mlqk} \cdot W'_m x^l(\phi_l(\hat{p}_q) + \Delta p_{mlqk}) \right]$$

- $\{x^l\}_{l=1}^L$: L=4 层多尺度特征图（ResNet C3~C6）
- $\hat{p}_q \in [0,1]^2$: 归一化坐标，$\phi_l$ 将其缩放到第 l 层分辨率
- 采样点数 = L × K = 4 × 4 = 16 个点

**优势**：无需 FPN——多尺度 deformable attention 天然实现在不同尺度间的信息交换。消融实验（Table 2）证实加 FPN 不提升性能。

### 4.4 架构（Figure 1, P.2）

**Encoder**：输入 C3~C6 四层特征图，用多尺度 deformable self-attention 处理。output 也是同分辨率的特征图。每层加 scale-level embedding（可学习的，不固定）。

**Decoder**：cross-attention 替换为多尺度 deformable attention（自注意力保持原样）。每个 object query 的参考点由 query embedding 通过线性层 + sigmoid 预测。检测头预测框相对于参考点的偏移（参考点作为框中心初值），进一步加速收敛。

### 4.5 额外改进

**Iterative Bounding Box Refinement**：每层 decoder 根据上一层的预测结果逐步精化 bbox。

**Two-Stage Deformable DETR**：第一阶段用 encoder-only 变体（去掉 decoder），每个像素作为 query 直接预测 bbox，选 top-scoring 作为 region proposals 送入第二阶段 decoder 做精化。避免 decoder self-attention 的 O(N²) 复杂度。

## 5. 实验

### 5.1 实验设置

- **数据集**: COCO 2017
- **Backbone**: ResNet-50（消融），ResNet-101 / ResNeXt-101（主实验）
- **配置**: M=8 heads, K=4 采样点，300 object queries，Focal Loss
- **训练**: 50 epoch（DETR 需要 500 epoch），学习率第 40 epoch 衰减

### 5.2 主要结果 (Table 1, P.7)

| 方法 | Epochs | AP | APS | APM | APL | GPU小时 | FPS |
|------|--------|-----|-----|-----|-----|---------|-----|
| DETR-DC5 | 500 | 43.3 | 22.5 | 47.3 | 61.1 | 7000 | 12 |
| **Deformable DETR** | **50** | **43.8** | **26.4** | **47.1** | **58.0** | **325** | **19** |
| + iter box refine | 50 | 45.4 | 26.8 | 48.3 | 61.7 | 325 | 19 |
| ++ two-stage | 50 | 46.2 | 28.8 | 49.2 | 61.7 | 340 | 19 |

**核心结论**：50 epoch 精度（43.8）超过 DETR 500 epoch（43.3），GPU 时节省 **21 倍**（325 vs 7000）。小物体 AP 提升 +3.9（26.4 vs 22.5）。

### 5.3 消融实验 (Table 2, P.8)

- 单尺度 → 多尺度输入：+1.7 AP（尤其是小物体 +2.9 AP）
- K=1（退化到 deformable conv）→ K=4：+0.9 AP
- 加多尺度 attention（跨尺度信息交换）：+1.5 AP
- 加 FPN/BiFPN：不提升

### 5.4 与 SOTA 对比 (Table 3, P.8)

| Backbone | AP | AP75 | APS | APL |
|----------|-----|------|-----|-----|
| ResNet-50 | 46.9 | 50.8 | 29.1 | 62.0 |
| ResNet-101 | 48.7 | 52.9 | 29.7 | 62.8 |
| ResNeXt-101 | 49.0 | 53.2 | 30.6 | 64.7 |
| ResNeXt-101+DCN | 50.1 | 54.6 | 31.1 | 64.7 |
| + TTA | 52.3 | 58.1 | 34.4 | 65.6 |

### 5.5 可能的不足

- 无序内存访问：deformable attention 的采样点分布不规则，比传统卷积仍慢 25%
- K=4 是默认值，但对大物体可能需要更多采样点
- 两阶段版本需要 encoder-only 的 proposal 生成，增加了复杂度

## 6. 一句话总结

Deformable DETR 用 data-dependent 稀疏 attention（每个 query 只关注 K=4 个可学习采样点）替代 DETR 的 dense attention，在 1/10 的训练成本下达到更高精度，是端到端检测走向实用的关键一步。
