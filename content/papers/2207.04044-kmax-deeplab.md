> **TLDR**: Cross-attention 和 k-means 本质上是同一件事——object queries 就是聚类中心，pixel features 就是数据点。关键区别在于：k-means 在聚类中心维度做 argmax（hard assignment），cross-attention 在空间维度做 softmax（soft weighting）。后者在视觉任务中收敛困难（像素数 >> query 数），前者效率高得多。把 cross-attention 的 spatial softmax 改成 cluster-wise argmax，R50 上 PQ 涨 5.2%，参数和 FLOPs 几乎不变，训练收敛更快，COCO 最终 58.0% PQ SOTA。用一句话：**Cross-attention = k-means with wrong normalization axis。**

## 1. TLDR

- **领域**: 全景/语义/实例分割 (Panoptic Segmentation)
- **任务**: 改进 mask transformer decoder 的 cross-attention 设计
- **问题**: 视觉分割中，cross-attention 在 H×W（数万像素）上做 softmax，每个 object query 要从海量像素中找到自己的目标物，训练初期 attention 几乎是均匀分布 → 收敛慢、效果差。这在 NLP 不是问题（输入输出等长），在视觉中是致命短板
- **核心贡献**: 发现 cross-attention 与 k-means 聚类的数学等价性，将 spatial softmax 改为**聚类中心维度的 argmax**，配合 deep supervision 解决不可导问题。简单到只有一个操作符不同，但 PQ 涨了 5.2%

## 3. 核心洞察

### 3.1 Cross-attention vs k-means

| | Cross-attention | k-means |
|---|---|---|
| query/中心 | $C$ (query projection) | $C$ (cluster centers) |
| key/数据 | $K_p$ (key projection) | $P$ (pixel features) |
| 亲和度 | $Q_c \times K_p^T$ | $C \times P^T$ |
| 归一化 | $\text{softmax}_{HW}$ (空间维度) | $\text{argmax}_N$ (聚类中心维度) |
| 更新 | 残差 + V projection + FFN | 直接加权平均 |

核心差异就一条**归一化轴**的选择：
- Spatial softmax (HW): 每个 query 在图像上找"热区"→ 像素量太大，梯度弥散
- Cluster argmax (N): 每个像素被分配到**唯一**的聚类中心 → 硬分配 + 参数只需关注 N 个中心

### 3.2 k-means cross-attention 公式

原始 cross-attention:
$$\hat{C} = C + \underbrace{\text{softmax}_{HW}(Q_c \times (K_p)^T)}_{\text{spatial-wise softmax}} \times V_p$$

k-means cross-attention:
$$\hat{C} = C + \underbrace{\text{argmax}_N(Q_c \times (K_p)^T)}_{\text{cluster-wise argmax}} \times V_p$$

↑ 就改了这一处。argmax 让每个像素只分配给一个 cluster，更新时完全基于该 cluster 内的像素特征。

### 3.3 不可导怎么办？

argmax 不可导，但作者发现一个巧妙的结构性优势：

argmax 的输入 logits $Q_c \times K_p^T$ 正好就是最终分割 mask 的 logits（因为 mask 预测也是 $F \times C^T$）。所以可以直接在每个 kMaX decoder 上加 **deep supervision**——把每个 decoder 的 attention map 当作辅助分割损失来监督，从而训练 Q/K 投影层的参数。

## 4. 架构

三组件：

1. **Pixel Encoder**: 任何 backbone（R50, MaX-S, ConvNeXt）
2. **Enhanced Pixel Decoder**: axial attention + bottleneck block，恢复分辨率、增强特征
3. **kMaX Decoder**: 6 个 decoder，每两个分配在 stride 32/16/8 的特征图上

整体架构就是 MaX-DeepLab 改了一个 operation，干净利落。

## 5. 效果

### COCO val 全景分割

| 方法 | Backbone | PQ |
|---|---|---|
| Mask2Former | R50 | 51.9 |
| **kMaX-DeepLab** | **R50** | **53.0** |
| CMT-DeepLab | MaX-S | 53.0 |
| **kMaX-DeepLab** | **MaX-S** | **56.2** |
| Mask2Former | Swin-L | 57.8 |
| **kMaX-DeepLab** | **ConvNeXt-L** | **58.0** |

R50 上比 Mask2Former (带 deformable/masked attention/point supervision) 高 1.1% PQ，且跑得快 3 倍。比 original cross-attention (MaX-DeepLab 同框架) R50 高 5.2% PQ。

## 6. 讨论与思考

### 6.1 为什么要用 argmax 而不是 softmax？

本质上是**归一化轴的选择问题**：
- 空间 softmax: 每个 query 在所有像素上找"哪些像素属于我"，输出是 HW 维的概率分布，像素间相互竞争
- 聚类 argmax: 每个像素在 N 个中心里找"我属于哪个中心"，输出是 N 维的 one-hot，中心间相互竞争

视觉分割中，N（~128）<< HW（数万），在 N 上做 argmax 的信号比在 HW 上做 softmax 强得多。这也是 k-means 的核心思想——hard assignment 比 soft assignment 收敛快。

### 6.2 跟 CMT-DeepLab 的区别

作者之前的 CMT-DeepLab 也用了聚类视角，但只是在 cross-attention 上加了一个**聚类更新项作为补充**。kMaX 则直接把 cross-attention 本身**替换成**聚类操作——更彻底也更简洁。

### 6.3 Multi-head 不需要了

因为 cluster-wise argmax 已经天然捕捉到聚类分配，multi-head 的"多个视角"不再需要。这解释了为什么 kMaX 用单头也能更好。

### 6.4 局限性

- 全监督框架，论文没有探索半监督/无监督扩展
- 可视化显示前三个 decoder 已经能产生合理聚类，后三个在 refine——可能有更高效的设计
- 大模型上过拟合（作者用 COCO unlabeled set 伪标签缓解了）
