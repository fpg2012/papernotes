> **TLDR**: Cross-attention 和 k-means 本质上是同一件事——object queries 就是聚类中心，pixel features 就是数据点。关键区别在于：k-means 在聚类中心维度做 argmax（hard assignment），cross-attention 在空间维度做 softmax（soft weighting）。后者在视觉任务中收敛困难（像素数 >> query 数），前者效率高得多。把 cross-attention 的 spatial softmax 改成 cluster-wise argmax，R50 上 PQ 涨 5.2%，参数和 FLOPs 几乎不变，训练收敛更快，COCO 最终 58.0% PQ SOTA。用一句话：**Cross-attention = k-means with wrong normalization axis.**

## 1. TLDR

- **领域**: 全景/语义/实例分割 (Panoptic Segmentation) **（P.1）**
- **任务**: 改进 mask transformer decoder 的 cross-attention 设计，实现端到端分割 **（P.1）**
- **问题**: 视觉分割中，cross-attention 在 H×W（数万像素）上做 softmax，每个 object query 要从海量像素中找到自己的目标物，训练初期 attention 几乎是均匀分布 → 收敛慢、效果差。这在 NLP 不是问题（输入输出等长），在视觉中是致命短板 **（P.2）**
- **核心贡献**: 发现 cross-attention 与 k-means 聚类的数学等价性，将 spatial softmax 改为**聚类中心维度的 argmax**，配合 deep supervision 解决不可导问题。简单到只有一个操作符不同，但 PQ 涨了 5.2% **（P.2-3）**

## 3. 相关工作背景

本文站在三条研究线的交叉点上：

1. **Transformers in Vision**（P.3）：Transformer encoder/self-attention 作为 backbone 已经在各种视觉任务中广泛使用 [94,32,70]。但作者指出这些方法大多直接从 NLP 移植而来。

2. **Mask transformers for segmentation**（P.3-4）：MaX-DeepLab [93] 首次将 mask transformer 引入端到端全景分割，后续有 MaskFormer [24]、K-Net [109]、CMT-DeepLab [106]、Panoptic SegFormer [65]、Mask2Former [23] 等一系列工作。**关键差异**：这些工作都在 cross-attention 上做各种改进（deformable attention [116]、masked cross-attention [23] 等），却没有质疑 cross-attention 本身的 softmax 轴选择是否适合视觉任务。

3. **Clustering methods for segmentation**（P.4）：传统方法如 k-means [72] 和 SLIC [1] 聚类像素强度，现代方法在语义特征上聚类 [13,15,18]。CMT-DeepLab [106] 讨论了 mask transformer 与聚类算法的相似性，但仅作为 cross-attention 的补充项。**关键差异**：本文彻底将 cross-attention 替换为 k-means 风格的聚类操作。

## 4. 核心方法

### 4.1 问题形式化

Panoptic segmentation 的目标是将图像 $\mathbf{I} \in \mathbb{R}^{H \times W \times 3}$ 分割为一组不重叠的 mask 及其语义标签 **（P.4）**：

$$\{y_i\}_{i=1}^K = \{(m_i, c_i)\}_{i=1}^K$$

其中 $m_i \in \{0,1\}^{H \times W}$ 是 ground truth mask，$\sum_{i=1}^K m_i \leq 1^{H \times W}$，$c_i$ 是类别标签。预测方式为 N 个 mask（N ≥ K）：

$$\{\hat{y}_i\}_{i=1}^N = \{(\hat{m}_i, \hat{p}_i(c))\}_{i=1}^N$$

最终 mask 预测通过 pixel features $\mathbf{F} \in \mathbb{R}^{HW \times D}$ 与 object queries $\mathbf{C} \in \mathbb{R}^{N \times D}$ 的点积获得 **（P.5, Eq. 3）**：

$$\mathbf{Z} = \underset{N}{\operatorname{softmax}}(\mathbf{F} \times \mathbf{C}^\mathrm{T})$$

### 4.2 核心洞察：Cross-Attention = k-means with wrong axis

**Cross-attention（P.5, Eq. 4）：**
$$\hat{\mathbf{C}} = \mathbf{C} + \underset{HW}{\operatorname{softmax}}(\mathbf{Q}^c \times (\mathbf{K}^p)^\mathrm{T}) \times \mathbf{V}^p$$

在空间维度 HW 上做 softmax → 每个 query 从所有像素中加权聚合信息。

**k-means clustering（P.6, Eq. 5-6）：**
$$\mathbf{A} = \underset{N}{\operatorname{argmax}}(\mathbf{C} \times \mathbf{P}^\mathrm{T})$$
$$\hat{\mathbf{C}} = \mathbf{A} \times \mathbf{P}$$

在聚类中心维度 N 上做 argmax → 每个像素被硬分配给唯一的中心。

**关键差异表格（P.6）：**

| | Cross-attention | k-means |
|---|---|---|
| 亲和度 | $Q^c \times (K^p)^\mathrm{T}$ | $C \times P^\mathrm{T}$ |
| 归一化轴 | 空间维度 HW（softmax） | 聚类维度 N（argmax） |
| 更新方式 | 残差 + V projection | 直接加权平均 |
| 参数 | Q/K/V 三个投影层 | 无参数 |

### 4.3 k-means Cross-Attention（P.7, Eq. 7, Figure 1）

$$\hat{\mathbf{C}} = \mathbf{C} + \underset{N}{\operatorname{argmax}}(\mathbf{Q}^c \times (\mathbf{K}^p)^\mathrm{T}) \times \mathbf{V}^p$$

**就这一处改动：** spatial-wise softmax → cluster-wise argmax。

关键设计难点和解法：

- **不可导问题**：argmax 不可导。尝试过 Gumbel-Softmax [48] 但效果不如简单方案。
- **Deep Supervision 解法**（P.7）：argmax 的输入 logits $Q^c \times (K^p)^\mathrm{T}$ 恰好等于最终 mask 预测的 logits $\mathbf{F} \times \mathbf{C}^\mathrm{T}$（因为 cluster centers 和 pixel features 的亲和度就是 mask 的分割 logits）。因此可以直接在每个 kMaX decoder 上加辅助分割损失，用匈牙利匹配的结果分配监督信号。
- **Multi-head 不需要**（P.7）：k-means 的单头 hard assignment 天然捕捉聚类分配，不需要多头视角。

### 4.4 Meta Architecture（P.7-8, Figure 2-3）

三组件：
1. **Pixel Encoder**: 任何 backbone（R50, MaX-S, ConvNeXt）
2. **Enhanced Pixel Decoder**: axial attention block + bottleneck block，恢复分辨率增强特征
3. **kMaX Decoder × 6**: 每两个分布在 stride 32/16/8 的特征图上，共 6 个 decoder

**训练策略（P.9-10）：**
- Loss: PQ-style loss + auxiliary semantic loss + mask-id CE loss + instance discrimination loss [106]
- Optimizer: AdamW, weight decay 0.05, backbone LR multiplier 0.1
- Augmentation: drop path, random color jittering, panoptic copy-paste
- COCO: batch size 64 on 32 TPU, 150k iterations, input 1281×1281
- Cityscapes: batch size 32, 60k iterations, input 1025×2049, 256 cluster centers

**新奇技巧 - Drop Query Regularization（P.9）：** 大模型用 256 个 query 反而掉点，但训练时随机 drop 一半 query（128），推理用全部 256 个，涨 0.1% PQ。

## 5. 实验

### 5.1 实验设置

- **数据集**: COCO [66]（P.11）、Cityscapes [28]（P.12）、ADE20K [112]（P.13）
- **评估指标**: PQ（全景）、AP（实例）、mIoU（语义）
- **Baselines**: MaskFormer [24]、K-Net [109]、CMT-DeepLab [106]、Panoptic SegFormer [65]、Mask2Former [23]、MaX-DeepLab [93]、Panoptic-DeepLab [22]、Axial-DeepLab [94] 等
- **Backbones**: ResNet-50, MaX-S (R50+axial), ConvNeXt-B/L

### 5.2 主要结果

**COCO val set（P.11, Table 1）：**

| 方法 | Backbone | PQ | 参数/FLOPS 优势 |
|---|---|---|---|
| kMaX-DeepLab | **R50** | **53.0** | 比 Mask2Former R50 高 1.1%，快 3× |
| kMaX-DeepLab | **MaX-S** | **56.2** | 比 CMT-DeepLab MaX-S 高 3.2% |
| kMaX-DeepLab | **ConvNeXt-L** | **58.0** | SOTA，比 Mask2Former Swin-L 高 0.2% |
| kMaX-DeepLab | ConvNeXt-L + COCO unlabeled | **58.1** | 伪标签微调 |

关键对比：R50 上 kMaX 比原始 cross-attention（MaX-DeepLab 同框架）**高 5.2% PQ，参数量几乎相同**（P.22, Table 4）。

**Cityscapes val set（P.12, Table 2）：**
- kMaX-DeepLab ConvNeXt-L: **68.4% PQ, 44.0% AP, 83.5% mIoU**
- 比 Mask2Former Swin-L 高 1.8% PQ、0.4% AP、0.6% mIoU
- 且 R50 上比 Mask2Former R50 高 2.2% PQ

**ADE20K val set（P.13, Table 3）：**
- kMaX-DeepLab ConvNeXt-L (1281): **50.9% PQ, 55.2% mIoU**
- 比 Mask2Former Swin-L 高 2.8% PQ

### 5.3 消融实验（P.22-23, Tables 4-5）

**Table 4 - Pixel-cluster interaction（P.22）：**
| 模块 | R50 PQ | MaX-S PQ |
|---|---|---|
| Cross-attention (baseline) | 47.5 | 52.0 |
| Dual-path cross-attention | 48.0 (+0.5) | 52.3 (+0.3) |
| **k-means cross-attention** | **52.7 (+5.2)** | **56.1 (+4.1)** |
| Dual-path k-means | 53.0 (+5.5) | 56.2 (+4.2) |

结论：性能提升主要来自 cluster-wise argmax，而非 deep supervision（给 baseline 加 deep supervision 反而掉 1.2%）。

**Table 5 - 解码器数量（P.22）：**
| (stride32, stride16, stride8) | R50 PQ | MaX-S PQ |
|---|---|---|
| (1,1,1) | 52.5 | 55.8 |
| **(2,2,2)** | **52.7** | **56.1** |
| (3,3,3) | 52.8 | 56.0（饱和） |

结论：6 个 decoder 足够，更多开始饱和。

**训练收敛**（P.23）：25k→50k→100k→150k 迭代，R50 上 PQ 48.8→51.3→52.7→53.0，150k 收敛。而 MaX-DeepLab 需要更多迭代（200k→400k 还在涨）。

### 5.4 实验不足

- **大模型过拟合**（P.11）：kMaX-DeepLab 从 ConvNeXt-B (57.2) 到 L (57.9) 只涨 0.7%，而 Mask2Former 涨 1.4%（Swin-B 56.4→Swin-L 57.8），说明 kMaX 的强表示能力导致在小数据集上更容易过拟合
- **论文未探索**：半监督/无监督扩展
- 可视化显示前三个 decoder 已经产生合理结果，后三个在 refine——可能存在更高效的设计

### 5.5 可视化洞察（P.14-15, Figures 4-5）

- 第一阶段聚类倾向于 over-segmentation（过分割），很多 cluster 被激活，后面逐步合并修剪
- **Part-to-whole 行为**（Figure 5 P.15）：大象的头顶、身体、鼻子在第一阶段被分别聚类，后面逐步合并成完整物体
- 第一轮 clustering 已经能区分不同语义（如人已经聚类得很好了），说明初始聚类不仅基于纹理/位置，还基于底层语义

## 6. 一句话总结

kMaX-DeepLab 通过将 cross-attention 中的 spatial softmax 替换为 cluster-wise argmax，揭示了 mask transformer 与 k-means 聚类的等价关系，以近乎零额外代价实现了全景分割的显著提升，是一个简洁而深刻的 insight-driven 工作。
