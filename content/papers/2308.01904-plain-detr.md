## TLDR

**领域**: 目标检测 / DETR

**任务**: 构建保持"朴素"设计的 DETR——单尺度特征图、全局 cross-attention 计算、无局部性约束——并达到与多尺度 + 局部性设计相当的性能。

**问题** (P.1): 原始 DETR 去掉了多尺度 FPN 和 region-based 特征提取，简洁优雅但收敛慢、精度低。后续工作（Deformable DETR, DAB-DETR, DINO-DETR）重新引入这些归纳偏置，精度上去了但违背了"少 bias 多通用"的设计原则。

**核心贡献** (P.1-2):
1. **Box-to-Pixel Relative Position Bias (BoxRPB)**：在 cross-attention 中加入 box 与像素之间的相对位置偏置，引导 query 关注物体区域。+8.9 mAP
2. **MIM 预训练**（SimMIM）：提供细粒度定位能力，在 plain 设计中是关键。+7.4 mAP
3. **朴素 DETR 达到 SOTA**：Swin-L + Object365 预训练，63.9 AP，超越 DINO-DETR（63.3），且完全不需要多尺度特征和局部注意力。

## 2. 相关工作

**DETR 发展史** (P.7)：原始 DETR (ECCV 2020) → Conditional DETR → DAB-DETR → DN-DETR → Deformable DETR → DINO-DETR。每一次改进都引入了或多或少的检测专用设计（多尺度、可变形注意力、RoI 采样）。Plain DETR 试图回归 DETR 的原始精神。

**Region-based 检测** (P.7)：Faster R-CNN → FPN → Cascade R-CNN → HTC，全部依赖多尺度 FPN。本文的 plain design 证明了单尺度特征已经够用。

**MIM 预训练** (P.7)：MAE/SimMIM 等 masked image modeling 已有研究，但很少用于构建完全的 plain 检测器。本文首次证明 MIM 能消除对多尺度特征的需求。

## 3. 核心方法

### 3.1 现代化的 Plain DETR Baseline (P.2-3)

从原始 DETR 出发，逐步集成近年训练技巧（不改架构），建立 37.2 mAP 的 strong baseline（Swin-T, 12 epoch）：

| 组件 | AP | 说明 |
|:-----|:--:|:-----|
| 基础 (Swin-T + 6 enc + 300 queries) | 22.5 | |
| + 合并 Transformer encoder 到 backbone | 23.1 | 不另外加 encoder |
| + Focal loss | 31.6 | |
| + 迭代精炼 (iterative refinement) | 33.1 | 每层预测相对于上层的 delta |
| + 两阶段 (content-related query) | 34.0 | 用前 300 置信度预测做 query |
| + Look forward twice | 34.8 | 利用前层 refined box 优化参数 |
| + Mixed query selection | 35.2 | 静态内容 query + 图像自适应位置 query |
| + Hybrid matching | **37.2** | 辅助 one-to-many 匹配 |

*Table 1 (P.3)*

### 3.2 Box-to-Pixel Relative Position Bias (P.3-4)

**动机**: 原始 DETR 的 cross-attention 常关注到无关区域（Figure 4, P.7）。BoxRPB 在 query 与像素的注意力计算中加入了 box 几何关系。

**原始 cross-attention**: $\mathbf{O} = \text{Softmax}(\mathbf{QK}^\top)\mathbf{V} + \mathbf{X}$

**加入 BoxRPB**: $\mathbf{O} = \text{Softmax}(\mathbf{QK}^\top + \mathbf{B})\mathbf{V} + \mathbf{X}$

其中 $\mathbf{B}$ 是 box 与像素之间的 4D 相对位置偏置。

{{< figure src="/figures/2308.01904-boxrpb.jpg" alt="BoxRPB 示意图" width="100%" >}}
*Figure 2 (P.4)：BoxRPB 计算流程。左上 + 右下两个角点与像素的偏移沿 x 和 y 轴分解后分别通过 MLP 生成偏置项。*

**Naive 版本**：用两个角点 $\Delta\mathbf{x}_1,\Delta\mathbf{y}_1,\Delta\mathbf{x}_2,\Delta\mathbf{y}_2$ 通过 MLP 生成 4D 偏置。效果很好但显存 26.8G，FLOPs 265.4G，不实用。

**轴向分解版本 (default)**：将 4D 解耦为 x 轴和 y 轴两个分量：

$$ \mathbf{B} = \text{unsqueeze}(\mathbf{B}_x, 1) + \text{unsqueeze}(\mathbf{B}_y, 2) $$

其中：
$$ \mathbf{B}_x = \text{MLP}_1(\Delta\mathbf{x}_1, \Delta\mathbf{x}_2), \quad \mathbf{B}_y = \text{MLP}_2(\Delta\mathbf{y}_1, \Delta\mathbf{y}_2) $$

性能几乎不变（50.9 vs 50.8），显存降至 9.5G，FLOPs 降至 5.8G（**降低 45 倍**）。见 Table 3a (P.5)。

**效果**: BoxRPB 使 cross-attention 聚焦到单个物体区域（Figure 4），+8.9 mAP（37.2→46.1）。

### 3.3 MIM 预训练 (P.4)

用 SimMIM（ImageNet 无标签）预训练 Swin backbone 权重。在 plain DETR 框架上带来：
- 仅 baseline（无 BoxRPB 无 MIM）：37.2
- +BoxRPB 无 MIM：46.1
- +MIM 无 BoxRPB：44.6
- +BoxRPB + MIM：48.7
- +BoxRPB + MIM + box reparam.：**50.9**

*Table 2 (P.4)*

**关键发现** (Table 5, P.6)：MIM 预训练可以消除对多尺度特征的依赖。用 MIM 后，$C^5 \rightarrow P^4$（单尺度 backbone + 单尺度 decoder）达到 50.9 mAP，与 $C^{3,4,5} \rightarrow P^{3,4,5}$（多尺度 backbone + 多尺度 decoder）51.1 几乎相同。即**单尺度 + plain 结构完全可行**。

### 3.4 Bounding box re-parameterization (P.4)

用类似 R-CNN 的归一化方式替代原始 DETR 的 [0,1] 缩放：

$$ t_x^l = (g_x - p_x^{l-1}) / p_w^{l-1},\quad t_y^l = (g_y - p_y^{l-1}) / p_h^{l-1} $$
$$ t_w^l = \log(g_w / p_w^{l-1}),\quad t_h^l = \log(g_h / p_h^{l-1}) $$

小物体提升显著（+2.9 APS），总 +2.2 AP。

## 4. 实验

### 4.1 消融

**BoxRPB 消融** (Table 3, P.5)：

- 轴向分解 vs 完整版：50.9 vs 50.8 AP，计算量降 45×
- 两角点 vs 单中心点：50.9 vs 48.0（角点携带了宽高信息）
- 与其他 attention 调制方法对比：BoxRPB 50.9 > SMCA 48.7 > DAB 48.4 > Conditional 48.3

**与局部注意力对比** (Table 4, P.5)：BoxRPB 全局注意力 50.9 > Deformable 50.2 > RoIAlign 49.6

**MIM 消融** (Table 5, P.6)：
- 多尺度 backbone + 多尺度 decoder：有 MIM 51.1 vs 无 49.6
- 单尺度 backbone + 单尺度 decoder：有 MIM 50.9 vs 无 48.0
- MIM 填补了多尺度到单尺度的性能差距

### 4.2 系统级结果 (Table 7, P.7)

COCO test-dev，Swin-L：

| 方法 | 预训练 | AP |
|:-----|:------:|:--:|
| DINO-DETR | - | 58.6 |
| **Plain DETR** | - | **60.0** |
| DETA | O365 | 63.5 |
| DINO-DETR | O365 | 63.3 |
| **Plain DETR** | O365 | **63.9** |

Plain DETR + Object365 达到 63.9 AP，超越所有依赖多尺度的 SOTA 检测器。

### 4.3 Plain ViT 对比 (Table 6, P.7)

用 ViT-Base + MAE 预训练，Plain DETR 与 Cascade Mask R-CNN 对比：
- Plain DETR: **53.8** AP（无 mask 监督，单尺度）
- Cascade Mask R-CNN: 53.7 AP（多尺度 FPN + mask 监督）

### 4.4 局限

- BoxRPB 计算中 K×H×W 的偏置矩阵仍有显存开销，需要轴向分解才能实际使用
- 仅验证了 Swin 和 ViT 两种 backbone，对其他架构（ConvNeXt 等）的泛化性未知
- MIM 预训练在 plain DETR 上提升巨大，但在其他检测器上提升中等，对此的解释不够深入

## 一句话总结

Plain DETR 证明了 BoxRPB + MIM 预训练足以替代多尺度特征和局部注意力，让朴素 DETR 设计重回 SOTA 竞技场（63.9 AP）。
